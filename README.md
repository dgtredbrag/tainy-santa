# Тайный Санта — MVP

Публичный full-stack сервис: React + TypeScript, FastAPI, PostgreSQL, Docker Compose.

## Запуск локально
1. Установите Docker Desktop.
2. Скопируйте `.env.example` в `.env` и задайте `JWT_SECRET` (длинная случайная строка).
3. Выполните `docker compose up --build`.
4. API: http://localhost:8000/docs
5. Frontend: http://localhost:5173

Это стартовая версия для разработки и тестирования. Перед публичным запуском обязательны HTTPS, почтовая верификация, rate limiting на уровне reverse proxy, резервные копии, мониторинг, миграции Alembic и независимый аудит безопасности.

## Основные правила MVP
- Создатель игры становится её администратором и может отдельно участвовать как игрок.
- Участники вступают по коду приглашения.
- Администратор видит полную жеребьёвку; участник — только своего подопечного.
- Запреты направленные: A → B не запрещает B → A.
- Жеребьёвка сохраняется атомарно только после нахождения и проверки решения.
- Чат доступен только двум сторонам назначения. Публичные ответы чата не содержат внутренних ID.
